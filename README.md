## 📖 About

This repository contains my personal portfolio website, created to showcase my projects, technical skills, professional experience and growth as a software developer.

The portfolio serves as a central place where recruiters, developers and potential collaborators can learn more about my background and explore the projects I have worked on.

## ✨ Features

* 📌 Personal and professional introduction
* 💻 Projects showcase
* 🛠️ Technologies and technical skills
* 📄 Access to my CV
* 🔗 Links to professional and developer profiles
* 📱 Responsive design
* 🎨 Custom visual design
* ⚡ Lightweight and fast web experience
